# 数据源融合策略（MVP）

## 目标

在保证可信度的前提下，把“硬信息 + 社区语境”融合到四张卡片里。

## 字段级优先级

- 作品名、年份、季度、主制作：AniList
- 基础叙述（背景、概要）：Wikipedia
- 梗、圈内称呼、传播语境：中文社区来源（可命中萌娘百科）

## 冲突处理

1. AniList 与 Wikipedia 冲突：以 AniList 硬信息为准。
2. 社区来源与前两者冲突：社区信息降级为“有说法认为/据说”。
3. 无足够证据：减少点数，不凑满。

## 萌娘百科使用边界

- 作为中文语境补充，不作为单一权威源。
- 输出时必须写来源域名，如 `via zh.moegirl.org.cn`。
- 不做整站抓取，按需检索并摘要即可。
